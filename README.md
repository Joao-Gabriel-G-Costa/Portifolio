# Portfólio — João Gabriel

Meu portfólio de Engenharia de Software, com pesquisa aplicada em previsão de precipitação e espaço para projetos Full Stack e backend.

## Projetos

- **Previsão de precipitação com LSTM:** pesquisa acadêmica com registros do INMET, metodologia e comparação dos resultados.
- **Gerenciador de tarefas:** projeto planejado com React, TypeScript, Java, Spring Boot e PostgreSQL.
- **Sistema de estoque:** projeto planejado com foco em backend e regras de negócio.

Os resultados da pesquisa foram conferidos no README e no relatório técnico do [projeto LSTM](https://github.com/Joao-Gabriel-G-Costa/previsao-precipitacao-lstm-goiania). As métricas representam execuções específicas e não uma previsão meteorológica operacional.

## Tecnologias do portfólio

HTML, CSS e JavaScript, sem dependências ou etapa de compilação. O site inclui filtros de projetos, abas de metodologia e resultados, comparação de MAE e RMSE e detalhes dos projetos planejados.

## Executar localmente

Abra `index.html` no navegador ou execute `python -m http.server 8000` nesta pasta e acesse `http://localhost:8000`.

## Hospedagem

A estrutura está preparada para o GitHub Pages: `index.html`, `styles.css`, `app.js` e `.nojekyll` ficam na raiz. Os caminhos relativos permitem publicar tanto na raiz de um domínio quanto em uma subpasta.

O envio dos arquivos não ativa o Pages. A publicação deve ser configurada separadamente, usando a branch `main` e a pasta raiz. Em uma conta pessoal, o site hospedado no GitHub Pages será público.

## Conteúdo

Este portfólio apresenta projetos pessoais e acadêmicos. Não contém código, dados ou informações internas do estágio. Os projetos planejados são identificados como tal e não têm demonstrações publicadas.
